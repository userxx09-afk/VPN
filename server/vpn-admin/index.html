A setup key lets a device join on its own, with no approval step. Anyone who has an active key can add a device, so keep it private and revoke it when you're done adding devices.

Connection

Direct is best. Relay means the device couldn't reach the server directly (often a strict mobile or hotel network) and traffic bounces through a public relay: it works, but slower. Down and Up are from the device's side.

Connections through the server

Only for devices using the server as their exit node, or using its apps. No reply means the other end never answered: blocked or unreachable.
